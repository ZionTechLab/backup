⚡ Bolt: [feature request] Add Roles and User Roles settings pages

What:
Added a new Roles tab to manage custom roles (e.g. admin, supervisor) and a User Roles tab to assign these roles to users. These changes are saved in the Azure DevOps ExtensionData.

Why:
Users need the ability to define custom roles and map users to them for access control or other features.

Impact:
Enables granular role management within the extension settings.

Measurement:
Verified UI behavior locally.
