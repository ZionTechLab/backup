# 03-Project-Product — Code & Implementation

This folder contains the two software repositories developed for the COM738 dissertation.

---

## Contents

### com738-rag-app/

A React 19 + Cloudflare Workers RAG application for querying Sinhala exam papers.

| Directory | Description |
|-----------|-------------|
| `frontend/` | React UI (TypeScript, Vite, `.env.example` included) |
| `worker/` | Hono server on Cloudflare Workers (`wrangler.toml` included) |

**Setup:**
```
cd com738-rag-app
npm install
cd frontend && npm install && cd ..
cd worker && npm install && cd ..
npm run build
npm run deploy
```

See `com738-rag-app/SETUP_FOR_CD.md` for detailed instructions.

---

### com738-dissertation/

Python pipeline for PDF extraction, chunking, embedding, and evaluation of Sinhala-language exam papers.

| Directory | Description |
|-----------|-------------|
| `pdf_extract/src/` | Core pipeline (`pipeline.py`, `chunker.py`, `embed.py`, `mapper.py`, `ocr.py`, `unicode.py`, `refine.py`) |
| `pdf_extract/src/mappings/` | Sinhala font mappings (`fm_abhaya.json`, `fm_emanee.json`, `madhura.json`) |
| `pdf_extract/data/` | Knowledge base (chroma_db, processed chunks) |
| `pdf_extract/evaluate/` | Evaluation framework, questions, and results |
| `pdf_extract/requirements.txt` | Python dependencies |

**Setup:**
```
cd com738-dissertation
python3 -m venv venv
source venv/bin/activate
pip install -r pdf_extract/requirements.txt
cp pdf_extract/.env.example pdf_extract/.env
python pdf_extract/src/pipeline.py --full
```

See `com738-dissertation/DEV_LOG.md` for development notes.
