# COM738 Dissertation — Formatting Rules

**Source:** Layout Guidelines + Extra Guidance (Wrexham University)

---

## Typography & Page Setup

| Setting | Required |
|---------|----------|
| Font | Times New Roman, 12pt, Normal |
| Alignment | Left-justified |
| Line spacing | 1½ (Main Body), Single (Preamble + End Matter) |
| Paragraph gap | 12pt between paragraphs |
| Paper | A4, 2.5cm margins all round |
| Printing | Single-sided |
| Headings | Initial Capitals — **NOT ALL CAPS** |

## Header / Footer

| Position | Content |
|----------|---------|
| Top Centre | Short dissertation title |
| Top Right | Page number |
| Bottom Left | Your full name |
| Bottom Right | MSc Computing |

---

## Three Parts

### Part 1 — Preamble (Single-spaced, Roman numerals ii, iii, iv...)
1. Title page (NO page number)
2. Acknowledgements
3. Abstract
4. Table of Contents
5. List of Figures
6. Glossary (if needed)

### Part 2 — Main Body (1½-spaced, pages restart at 1)

**Product-Based Track (RAG System):**

| Ch | Chapter | Notes |
|----|---------|-------|
| 1 | Introduction | Background, problem, aim, objectives, scope, overview |
| 2 | Literature Review | Thematic grouping. Critical analysis. Identify gaps. |
| 3 | Methodology | Approach, data collection, tools, ethics, validity |
| 4 | Investigation & Analysis | Deep-dive into problem. Requirements. Existing systems. |
| 5 | Design | System architecture, UML diagrams, DB schema, wireframes |
| 6 | Implementation | How you built it. Code snippets. Screenshots. Challenges. |
| 7 | Evaluation of Product | Testing approach. Results. Compare to requirements. User feedback. |
| 8 | Critical Evaluation | Strengths ✓, Weaknesses ✗, Constraints ■, Future Work → |
| 9 | Conclusion | Restate aims. Did you achieve them? Key findings. 2-3 pages max. |

### Part 3 — End Matter (Single-spaced, page numbers continue)
1. References (every source cited in-text)
2. Bibliography (consulted but not cited)
3. Appendix 1 — Project Proposal (A1.1, A1.2...)
4. Appendix 2+ — Survey forms, raw data, code, ethics

---

## Pre-Submission Checklist

### MUST Do
- [ ] Times New Roman, 12pt, left-aligned
- [ ] 1½ spacing in Main Body
- [ ] A4, 2.5cm margins
- [ ] Single-sided printing
- [ ] Title page: NO number
- [ ] Preamble: Roman numerals
- [ ] Main Body: pages restart at 1
- [ ] Every chapter = new page
- [ ] Sections (1.1, 1.2) = NO new page
- [ ] Headings: Initial Caps only
- [ ] Header/footer as specified
- [ ] Appendix 1 = Project Proposal
- [ ] 15,000–20,000 words (Main Body only)

### NEVER Do
- [ ] ❌ ALL CAPS headings
- [ ] ❌ Page number on title page
- [ ] ❌ New ideas in Chapter 9
- [ ] ❌ Hide weaknesses in Chapter 8
- [ ] ❌ Double-sided printing
- [ ] ❌ Under 15K or over 20K words

---

## Word Count Rules

| Section | Counted? |
|---------|----------|
| Title page, Abstract, Contents | ❌ NO |
| Chapter 1–9 (Main Body) | ✅ YES |
| References, Bibliography, Appendices | ❌ NO |
