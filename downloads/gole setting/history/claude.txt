2. Problems solved, with approach
Balance sheet report showing wrong current-month values when a reporting item had no previous-month data. Root cause: INNER JOIN in the update loop silently dropping rows. Fix: LEFT JOIN + ISNULL(Val,0); also flagged the same defect in the PROFITTR block.
SonarQube VM exposed publicly on port 9000 (security escalation from Group IT). Approach: disabled NSG any-to-any rules, shut down the VM, evaluated NSG service tags, IP restrictions, self-hosted DevOps agent on the same VM, and free reverse proxy options (Nginx, Cloudflare); planned a private network connection with Mahendra.
On-prem WAF must be first public entry point constraint in the AFD design. Approach: evaluated Cloudflare Tunnel (cloudflared) hosting options — on-prem vs. Azure Container Instance in a Tunnel VNet with peering (App Service ruled out); mapped domain-based routing, X-Azure-FDID validation, NSG allowlisting.
Single-origin routing for Angular + .NET on Azure App Services — compared APIM, App Gateway, AFD, YARP, Cloudflare, Nginx; recommended Nginx inside the Angular App Service container to remove CORS issues at zero extra cost.
