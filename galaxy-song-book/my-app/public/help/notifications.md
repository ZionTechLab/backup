## What Each Toggle Does

| Setting | When it fires |
|---|---|
| New Assignment | You're assigned a new activity |
| Approval Requests | Something needs your approval |
| TBD Resolution | An item marked "to be decided" gets resolved |
| Weekly Digest | A weekly summary of activity |
| Mobile Push | Push notifications to the mobile app |
| Desktop Notifications | Browser notifications while the app is open |

Flip any switch to turn that notification on or off — it saves immediately, no separate Save button.

## Note

This screen is currently a prototype — preferences aren't yet wired to a real notification pipeline, so toggling here doesn't change what you actually receive yet.
