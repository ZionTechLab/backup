# Search

Every screen in the app is reachable from one search box, without digging through the drawer.

## Opening Search

Click the search box in the top bar — it says **"Search or jump to..."** — or use the keyboard shortcut:

| Shortcut | Action |
|---|---|
| `Ctrl+K` (Windows/Linux) or `⌘K` (Mac) | Open search, from anywhere in the app |
| `Esc` | Close search |

![Search box in the top bar](/help/images/search-bar.png)

## Using It

Once search is open, just start typing. It filters as you type, matching against both the screen name and its module (e.g. typing "ledger" finds **General Ledger** under *Accounts*).

![Search results list](/help/images/search-menu.png)

| Key | Action |
|---|---|
| Type | Filter the list by name or module |
| `↓` / `↑` | Move the highlighted selection down/up |
| `Enter` | Open the highlighted result |
| Mouse click | Open that result directly |

## What It Searches

Only screens you have access to, and only real screens — group headers like "Petty Cash" or "Masters" won't show up on their own, but everything underneath them will. Results are capped at the first 25 matches, so a more specific search term gets you there faster.
