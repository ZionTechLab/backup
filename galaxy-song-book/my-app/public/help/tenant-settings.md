# Tenant Settings

*Mock illustration below — not a real screenshot of your instance.*

![Tenant settings page](/help/images/tenant-settings.svg)

This is different from every other item in the [User Menu](user-menu.md) — it doesn't change anything about your own account. It sets the **defaults for the whole tenant**, and every user still keeps the ability to override their own [Theme](theme.md) on top of it.

## Theme Defaults

| Setting | What it sets |
|---|---|
| Display Date Format | The default date format shown throughout the app (e.g. `YY-MMM-DD`) |
| Default Mode | Light or dark, for anyone who hasn't picked their own |
| Default UI Style | The default component visual style |
| Default Color Palette | The default accent color scheme |

## Behavior

| Setting | What it controls |
|---|---|
| Return to list after save | After saving a record, go back to its list screen instead of staying on the form |
| Show theme controls to users | Whether users can see and use the Theme option at all, or only administrators can |
| Searchable dropdowns | Whether select fields across the app get a type-to-filter search box |
| Table column visibility toggle | Whether data tables show the gear icon to show/hide columns |
| Table CSV export | Whether data tables offer a CSV export button |
| Pin action columns to the right | Moves each table's action buttons (edit/delete) to the far right column instead of the left |

## Who Can Use This

This affects every user in the tenant at once — treat it as an admin-level setting, even though it's reachable from the personal account menu.
